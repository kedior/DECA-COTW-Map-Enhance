# DECA COTW 地图增强油猴脚本

这是一个为 [DECA theHunter: COTW 地图](https://mathartbang.com/deca/hp/map.html) 增加的种群分数筛选工具。

它把地图左侧的种群树与存档中的个体分数结合起来，帮助你快速找出符合条件的兽群，并在地图上定位。

## 适合什么场景

在 COTW 中管理某个物种的种群时，常常不是只想找“分数最高的兽群”，而是想根据兽群里**每只动物的分数**决定去哪里狩猎。例如：

- 想保留低分和高分个体，只处理某个中间分数段的动物；
- 想快速找到至少有一只动物落在指定分数区间的兽群；
- 想查看一个兽群内各只动物的分数，而不必逐个点位手动核对存档信息；
- 只关注某个物种，暂时把不符合条件的该物种兽群从地图显示中取消勾选。

例如，养黄鹿时，如果计划保留 2 级和 5 级个体、优先处理 3–4 级个体，可以输入对应的分数范围。  
脚本会找出**至少有一只个体**分数命中范围的兽群，并勾选这些兽群，方便你在地图上逐点查看和安排狩猎。

> 筛选结果是“兽群”粒度：只要群内有一只个体命中区间，就会勾选整个兽群；
> 脚本不会替你判断或选择群内要击杀的具体动物。

## 安装

1. 在浏览器中安装 Tampermonkey，也就是油猴脚本。
2. 在 Tampermonkey 中新建脚本，将 `cotw-population-filter.user.js` 的全部内容粘贴进去并保存。
3. 打开或刷新 [DECA theHunter: COTW 地图](https://mathartbang.com/deca/hp/map.html)。
4. 按地图原有方式导入存档。完成后，页面右上角会出现“种群分数筛选”面板。

## 使用方法

1. 在“物种”下拉框中选择要处理的物种。
2. 输入最小分数和/或最大分数。分数边界**包含在范围内**；留空表示该方向不限制。
3. 点击“筛选并勾选”。符合条件的该物种兽群会被勾选，不符合条件的该物种兽群会被取消勾选；其他物种的勾选状态不变。
4. 在地图上查看已勾选兽群对应的位置。需要查看某个兽群的个体分数时，展开种群树中该兽群旁的箭头。
5. 点击“全部取消”可以取消种群树中的所有勾选，不限于当前选择的物种。
6. 更新存档时，需要重新点击筛选按钮来同步数据。

面板标题栏可以拖动；单击标题栏可折叠或展开面板。

## 分数与筛选规则

- **有个体分数时**：页面成功读取存档个体数据后，兽群下方会显示每只动物的分数。只要其中至少一只个体命中所设区间，整个兽群就会被勾选。命中的个体分数会以绿色突出显示。
- **没有个体分数时**：脚本退回到地图种群树显示的“最高分”，按兽群最高分判断是否符合范围。面板状态会注明“按最高分”。
- 面板中的统计信息会显示当前物种的兽群总数、达标兽群数；有个体分数时，还会显示命中的个体数。
- 筛选操作只修改当前选中物种的兽群勾选状态；“全部取消”则会清空整棵种群树的勾选。

如果没有看到个体分数，或统计信息显示“按最高分”，请确认存档已按地图页面的方式导入，并等待页面解析完成。
脚本仍可使用最高分进行筛选，但这时无法按群内每只动物的分数精确判断。

## 使用提醒

本脚本用于辅助查看和筛选地图上的兽群，不会修改存档，也不会自动执行狩猎操作。
分数筛选结果可帮助你缩小目标范围，最终仍请结合游戏内实际情况判断。
