# DECA COTW 地图增强油猴脚本

为 [DECA theHunter: COTW 地图](https://mathartbang.com/deca/hp/map.html) 新增功能：

- 按物种和分数区间筛选动物种群
- 支持查看种群内所有个体的分数

脚本主要用于辅助养猎，例如：
养黄鹿时候，需要保留2级和5级个体，击杀3-4级个体。
这个脚本可以快速筛出包含个体分数位于 126-240 的种群，方便逐点定位击杀。

## 安装

1. 浏览器安装 Tampermonkey 油猴脚本
2. 新建脚本，粘贴 `cotw-population-filter.user.js` 内容保存
3. 打开 [DECA theHunter: COTW 地图](https://mathartbang.com/deca/hp/map.html)

## 使用

存档目录拖入页面左侧页面后，右上角面板：

| 控件                | 说明                                             |
| ------------------- | ------------------------------------------------ |
| 物种                | 下拉框选择                                       |
| 最小分数 / 最大分数 | 筛选区间，留空为不限                             |
| 筛选并勾选          | 任一个体分数命中区间的兽群打勾显示，其余自动取消 |
| 全部取消            | 清空整棵树的勾选                                 |

面板可拖拽移动（按住标题栏），单击标题折叠 / 展开
